# SQL Teo Me Why (`sql-tmw`)

Este repositório reúne os códigos, exercícios práticos e o projeto final desenvolvidos ao longo do curso de SQL ministrado por Teo Calvo (Teo Me Why). O objetivo principal é documentar o aprendizado em modelagem de dados, linguagem de consulta (SELECT, agregações, subqueries, CTEs) e manipulação estrutural de banco de dados (DDL e DML).

---

## 📁 Estrutura do Repositório

```text
sql-tmw/
├── exercicios/       # Resoluções dos exercícios propostos nas aulas
├── queries/          # Scripts SQL de consultas, manipulação de dados (DML) e estrutura (DDL)
├── projeto final/    # Projeto prático final de consolidação do curso
└── .gitignore        # Arquivo de configuração de arquivos ignorados pelo Git
```

---

## **🛠️ Tecnologias e Ferramentas**

- **SQL (Structured Query Language):** Consultas analíticas, agregações, filtros (`WHERE`, `HAVING`), junções (`JOIN`), CTEs (`WITH`) e comandos DDL/DML (`CREATE`, `DROP`, `INSERT`, `UPDATE`, `DELETE`).
- **Python:** Scripts de automação, ingestão e integração de dados com bancos relacionais.
- **SQLite / SGBD Relacional:** Motor de banco de dados utilizado para execução e persistência das queries.
- **Git & GitHub:** Controle de versão e documentação do código.

---

## **🎯 Conteúdo das Pastas**

1. **exercicios/**: Lista de desafios práticos para fixação de conceitos de consulta e transformação de dados.
2. **queries/**: Conjunto de scripts organizados por tópicos de estudo (DML, DDL, funções de janela/string, agrupamentos).
3. **projeto final/**: Construção de uma pipeline/estudo de caso completo aplicando os conceitos aprendidos no curso.
